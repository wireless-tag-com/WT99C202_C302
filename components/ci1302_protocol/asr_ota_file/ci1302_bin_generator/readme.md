# 🏭 启英泰伦分区固件生成说明

## 💡 1. 实现原理

从 [启英泰伦官网平台](https://aiplatform.chipintelli.com/home/index.html) 生成素材包，放到本目录的对应文件夹内，通过脚本生成对应的bin文件。


---

## 🔧 2. 具体步骤

### 步骤1：生成素材包
在启英泰伦官方平台上，用目标唤醒词和命令词生成新的素材包，具体生成请查看官方资料，快速流程可参考下方说明。

### 步骤2：放置ASR文件
将素材包中`GfstCmd\[0]asr_chinese_CI1302_V00927.dat`和`GfstWake\[1]asr_chinese_CI1302_V00927.dat`放入`ci1302_bin_generator\asr`目录下，替换原有的两个同名文件。

> 📝 **特殊情况**：如果新生成了只有唤醒词没有命令词的素材包，就把`asr\[1]asr_chinese_CI1302_V00927.dat`删掉

### 步骤3：放置用户文件
同理将素材包`CmdWordStructure\[60000]{cmd_info}.xlsx`替换`ci1302_bin_generator\user_file\cmd_info`下的同名文件。

### 步骤4：运行生成脚本
运行`generate_bins.bat`

### 步骤5：验证生成结果
显示如下内容则说明生成成功：

```
========================================
所有 bin 文件生成完成！
========================================

生成的文件：
- asr\asr.bin
- user_file\user_file.bin

Press any key to continue . . .
```
